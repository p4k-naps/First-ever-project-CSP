What: I decided to make a game about killing goblins! The hero goes on a journey fighting different types of goblins.
It begins with the user in the home menu and then it cuts to a shopping section. From there the user has a multitude of
options to select weapons from. Each weapon has its respective cost, damage type, damage value, and durability. Through 
purchasing a weapon can the user go into the battle, from there the user has to click ready and then begin clicking in 
order to do damage! Each click will do damage to the goblins and if you have a weapon damage type thats correspondant to 
the goblin weakness you get a critical hit and do 2x damage! But each click will decreasethe weapons durability, until it
goes below zero in which you will be sent back to the shop. But no worries! Each click will provide money and each kill 
grants money. You will repeat this cycle choosing the best weapon each time and then kill the final boss to win!.
